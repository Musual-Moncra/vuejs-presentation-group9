## Cách chạy nhanh Demo trên máy Windows (khi thuyết trình)

1. Tải toàn bộ repo về máy (bấm **Code → Download ZIP** và giải nén, hoặc `git clone`).
2. Nháy đúp chuột vào file **`Mo_Demo_VueJS_Windows.bat`**.
3. Lần đầu file sẽ tự chạy `npm.cmd install`, sau đó tự bật trình duyệt tại `http://localhost:5173`.
